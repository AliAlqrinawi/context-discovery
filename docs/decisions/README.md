# Engine-repository decisions (ADR-E)

Decisions that belong to *this* repository's experiments and research programme rather than to
the engine's frozen contract. The architecture repository (`context-discovery-architecture`)
holds ADR-A0xx, the contract; the backend holds ADR-B00x, its own design. An ADR-E records how a
measurement is to be run and read - its questions, arms, corpus, protocol and pre-registered
outcomes - before it runs, so the result cannot be assembled around whatever it turns out to be.
